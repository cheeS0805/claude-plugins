# Налаштувати landing-guard у проєкті

Без файлу `.claude/landing-guard.json` плагін нічого не робить. Твоє завдання — **запропонувати** вміст цього файлу. Записує його **користувач сам**: хук забороняє Claude редагувати цей файл, бо в ньому список справжніх телефонів і правила захисту.

## 1. Оглянути проєкт

- **Сторінки:** які `.html` віддаються відвідувачам (зазвичай `index.html`).
- **Телефони:** усі `href="tel:…"` і видимі номери на сторінках. Для кожного — чий він. **Не вгадуй імена**: спитай користувача, і перепитай, чи всі номери справжні й актуальні.
- **Згенеровані файли:** `package.json` → скрипти збірки (`sass`, `tsc`, бандлери). Що вони пишуть і з чого. Наприклад `styles.css` ← `src/scss/`.
- **Збірка:** яку команду запускати для якого джерела.
- **Перевірка:** чи є скрипт перевірки (`npm run verify`, `test`, `lint`). Якщо нема — `check` не задавай, або запропонуй лише збірку.
- **План:** чи є файл плану з розділом `## Прогрес` і пунктами `- [ ]` / `- [x]`.

## 2. Скласти файл

```json
{
  "phones": [
    { "name": "Максим", "tel": "+380633890618", "text": "063 389 06 18" }
  ],
  "phoneText": "0\\d{2} \\d{3} \\d{2} \\d{2}",
  "pages": ["index.html"],
  "generated": {
    "styles.css": "src/scss/",
    "script.js": "src/script.ts"
  },
  "build": [
    { "match": "^src/scss/", "run": "npm run build:css" },
    { "match": "^src/", "run": "npm run build:ts" },
    { "match": "^(package|tsconfig)\\.json$", "run": "npm run build" }
  ],
  "check": {
    "match": ["^index\\.html$", "^src/", "^package\\.json$"],
    "run": "npm run verify:quick"
  },
  "plan": "PLAN.md"
}
```

- `phoneText` — регулярний вираз того, як номер виглядає в тексті сторінки (тут — український «0XX XXX XX XX»). Змінюй, якщо на сайті інший формат.
- `build` — перше правило, у якого `match` (регулярний вираз шляху) підходить, і виконується.
- `check.run` має повертати код ≠ 0, коли щось зламано; рядки, що починаються з «❌», хук покаже Claude.
- Непотрібні поля просто не пиши.

## 3. Передати користувачу

Покажи готовий JSON і поясни кожне поле одним реченням. Попроси створити `.claude/landing-guard.json` вручну й зберегти. Після цього перевір:

1. JSON валідний (`node -e "JSON.parse(require('fs').readFileSync('.claude/landing-guard.json','utf8'))"`).
2. Хуки живі: спробуй відредагувати згенерований файл — має бути відмова з підказкою.
3. Перезапуск сесії — на старті має з'явитися «де ми зупинились».
